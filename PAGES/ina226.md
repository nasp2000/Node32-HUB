# INA226 — `/ina226`

> One-stop reference for the **INA226 current/power monitor page**: purpose, layout,
> every button/input, client logic, API endpoints, persistence and the firmware-side
> I2C measurement engine. Written for both humans and AI agents.

---

## 1. Objective

Configure and read the **INA226 bidirectional current/power monitor** (I2C): live bus
voltage / current / power / shunt voltage, sensor enable + auto-read interval, hardware
calibration (I2C address, shunt resistance, max expected current, ADC averaging, display
unit), per-measurement visibility flags, and monitor/CSV output injection. One-shot
reads via "Measure Now"; settings persist to LittleFS and apply without reboot.

## 6. Client-side logic (inline JS in `page_ina226_asset.h:200-348`)

- **`t(key, fallback)`** — delegates to `window._t`, else hardcoded English fallback.
- **`uiLocale()`** — `localStorage ui_lang_code` or `document.lang` → `en-GB` / `pt-PT`.
- **`updateDisplay(d)`** (`:211-250`) — `last_bus_v.toFixed(3)` V; current ×1000 + `toFixed(1)` mA when `current_unit===1` else `toFixed(4)` A (updates `#currentUnitLbl`); power `toFixed(3)` W; shunt V×1000 `toFixed(3)` mV; timestamp via `sensorLastReadingPrefix` (`"📅 Last reading: "`) or `hx711NoReading` (`"No reading"`). Missing fields leave old values untouched.
- **`loadConfig()`** (`:252-280`) — `GET /api/ina226-config` (`no-store`), fills all inputs, calls `updateDisplay(d)`; if `last_reading_time` is 0 → auto `measureNow()` after 600 ms. Runs via `setTimeout(loadConfig, 150)`.
- **`saveConfig()`** (`:282-318`) — builds JSON (`sensor_enabled`, `read_interval_sec`, `i2c_addr`, `shunt_ohm`, `max_current_a`, `averaging`, `current_unit`, `show_*`, `inject_to_buffer`, `output_csv`), POSTs as `application/json`; checks **`d.ok`** (not the `d.success` convention used e.g. by `/access`). No arrow functions — project rule honoured.
- **`showStatus(msg, type)`** (`:333-343`) — prefers `customAlert(msg)`, so the `#status` div fallback is effectively dead when `customAlert` exists.

## 7. Server API

Handlers in `chatgpt/src/webpages/handlers_unified/sensor_handler.cpp:487-508` (`#if ENABLE_INA226==1`).

### `GET /api/ina226-config` (`:489-492`)

Returns `ina226ConfigManager.toJson()` (`chatgpt/src/sensors/sensor_ina226_config.cpp:110-135`):

```json
{
  "sensor_enabled": true, "i2c_addr": 64, "shunt_ohm": 0.1, "max_current_a": 10.0,
  "averaging": 4, "current_unit": 0, "read_interval_sec": 5,
  "inject_to_buffer": false, "output_csv": true,
  "show_bus_voltage": true, "show_shunt_voltage": false, "show_current": true, "show_power": true,
  "alert_current_max": 0.0, "alert_power_max": 0.0,
  "last_bus_v": 0.0, "last_shunt_v": 0.0, "last_current_a": 0.0, "last_power_w": 0.0,
  "last_reading_time": 0
}
```

### `POST /api/ina226-config` (`:494-501`)

`updateFromJson(req.body)` (`sensor_ina226_config.cpp:137-163`): applies every present key,
re-applies averaging to the live driver, `saveToFile()`. Responses: `{"ok":true}` (200) or
400 `{"ok":false,"msg":"Erro ao guardar config INA226"}` (hardcoded PT — see INA-5).
**No range validation** on any field (see INA-2).

### `POST /api/ina226-measure` (`:503-507`)

`performReading()` then full `toJson()` (same shape as GET), so the client reuses `updateDisplay(d)`.
Returns stale/zero readings (not an error) when the sensor is disabled or uninitialised.

## 8. Persistence

`INA226ConfigManager : SensorConfigBase` — default file **`/config/sensor_ina226.json`**
(`chatgpt/src/sensors/sensor_ina226_config.h:86`). `SensorConfigBase::saveToFile()`
(`chatgpt/src/sensors/sensor_config_base.h:101-110`) writes `.tmp` → drops empty writes
(`bytes==0` → remove, return false) → `LittleFS.rename()` over the original (atomic pattern).
`initFilesystem()` loads or creates with struct defaults (`:29-47`); `periodicPersist()`
(`:65-69`, driven from `chatgpt/src/loop_blocks.h:33`) re-saves on change. LittleFS slot also
registered as `addPage("sensor_ina226", 4096)` (`chatgpt/src/ConfigManager.cpp:925,2026`).
NOT via `ConfigManager`/NVS — standalone sensor JSON file.

## 9. Runtime engine

- **Driver** `INA226Sensor` (`chatgpt/src/sensors/sensor_ina226.h`, `.cpp:27-124`): `begin(addr,
  shuntOhm, maxCurrentA)` checks manufacturer ID `0x5449` but continues on mismatch (clone
  tolerance, `:33-38`), software reset, calibration `cal = 0.00512 / (current_lsb * shunt)`
  with `current_lsb = maxCurrent/32768`, default config AVG_4 + 1.1 ms conversions, continuous
  mode (`:44-57`). `readAll()` reads bus (1.25 mV/LSB), shunt (2.5 µV/LSB, signed), current
  (`raw * lsb`), power (`raw * 25 * lsb`).
- **Manager** `INA226ConfigManager::performReading()` (`sensor_ina226_config.cpp:46-66`):
  skips when uninitialised/disabled or driver not ready; caches `last_*` + `last_reading_time`
  (`gettimeofday`), injects to monitor buffer when enabled, `markReadingDone()`.
- **Injection** `injectToBuffer()` (`:72-89`): CSV `"INA226,voltage,<V>,current,<I>,<A|mA>,power,<W>W"`
  or human `"⚡ INA226: <V>V <I><unit> <W>W"` (unit follows `current_unit`) via
  `injectDataToRXBuffer(msg, "INA226")`.
- **Scheduling**: boot `ina226ConfigManager.begin()` after sensor-config ready
  (`chatgpt/src/sensors/sensor_config.cpp:140-143`); loop auto-read when
  `shouldAutoRead()` elapsed (`chatgpt/src/loop_blocks.h:29-34`); I2C scan probe
  (`chatgpt/src/i2c_scan.cpp:12,85`).
