# MQ135 Air Quality — `/mq135-config`

> One-stop reference for the **MQ-135 air-quality page**: purpose, layout, every
> button/input, client logic, API endpoints, persistence and the firmware-side
> gas-measurement engine. Written for both humans and AI agents.

---

## 1. Objective

Configure and read the **MQ-135 analog gas sensor**: master enable, reading
interval, AHT20 temperature/humidity compensation, clean-air calibration (R0),
ADC pin, per-gas enable toggles + ppm offsets, monitor output format, on-demand
measurement, and live display of CO2 (corrected), CO, NH3, NOx, Alcohol,
Benzene, Smoke and a computed AQI with warm-up status.

## 4. Inputs

| Input | ID / type / range | Notes |
|---|---|---|
| Enable sensor | `#sensorEnabled`, checkbox, default checked | maps to `sensor_enabled` |
| Interval | `#readInterval`, select 60/120/180/300/600/1800/3600/10800/21600/43200/86400 s, default 60 | same scale as env sensor page; server clamps to min 60 (`sensor_mq135_config.cpp:300`) |
| Env compensation | `#useEnvCompensation`, checkbox, checked | `use_env_compensation`; uses AHT20 temp/humidity when available |
| R0 | `#r0Value`, number step 0.01 min 0.01, default `76.63` | clean-air resistance; `= MQ135_R0_DEFAULT` (`sensor_mq135.h:46`) |
| ADC pin | `#adcPin`, number 0–47, default `4` | **mismatches firmware default GPIO5** (see MQ135-4) |
| Gas enables | `#en_co2/co/nh3/nox/alcohol/benzene/smoke/aqi`, checkboxes | benzene/smoke unchecked by default; rest checked |
| Gas offsets | `#off_co2` (±200 step 1), `#off_co/nox/nh3/alcohol` (±50 step 0.1), `#off_benzene` (±20) | added to ppm in `performReading`; **smoke and AQI have no offset input** |
| Monitor output | `#injectBuffer` (checked), `#outputPretty` (off), `#outputCSV` (checked) | pretty/CSV mutually exclusive client-side |

## 6. Client-side logic (inline JS in `page_mq135_config_asset.h:285-584`)

- **`loadConfig()`** (`:389`) — `GET /api/mq135-config` (`cache:no-store`), fills all checkboxes/selects/R0/ADC pin, per-gas `*_en`/`*_offset` keys, then `updateReadingValues(cfg)`; if `last_reading_time == 0` auto-calls `measureNow()` after 600 ms; delayed 150 ms at boot (`:583`) so `/api/lang` wins the radio.
- **`updateReadingValues(cfg)`** (`:431`) — timestamp via `toLocaleTimeString/DateString(uiLocale())`; warm-up badge (`✅ Sensor Stable` vs `⏳ Warmup: m:ss remaining`); per-gas `sv()` with 1 decimal (AQI 0), trend arrows (`trendArrow`, `prevValues`), colour themes (`mqTone` + `applySensorValueTheme`); raw ADC / Rs / Rs-R0 ratio cards; AQI label via `aqiInfo()`.
- **`saveConfig()`** (`:487`) — builds flat JSON (`sensor_enabled`, `read_interval_sec`, `use_env_compensation`, `inject_to_buffer`, `output_pretty`, `output_csv`, `r0`, `adc_pin`, `co2_en/_offset` … `aqi_en`; **no `smoke_offset`/`aqi_offset` sent**), POSTs JSON, `disableBtn` + `showLoading()` / `hideLoading()` + `enableBtn`.
- **`measureNow()` / `calibrateR0()`** (`:531`, `:544`) — as per Buttons; calibrate assumes clean air (`'(clean air assumed)'`).
- **Helpers** — `t()` wraps `window._t`, `uiLocale()` (`en-GB`/`pt-PT`), `aqiInfo()` (6 bands), `mqTone()` per-gas colour thresholds, `pickReadableTextColor()`, pretty⊕CSV mutual exclusion (`:571-576`). `showStatus()` prefers `customAlert` and only falls back to `#status` (`:558-568`).
- Uses `customAlert`, `showSavedCard`, `disableBtn/enableBtn`, `showLoading/hideLoading`; page script also uses an arrow function (`:408`), breaking the no-arrow-functions rule (see MQ135-6).

## 7. Server API

Handlers in `handlers_unified/sensor_handler.cpp:401-451`, all `#if ENABLE_MQ135==1`.

### `GET /api/mq135-config` (`:401`)

Returns `mq135ConfigManager.toJson()` (`sensor_mq135_config.cpp:222`): flat config keys (`sensor_enabled`, `adc_pin`, `r0` (4 dec), `rl`, `read_interval_sec`, `use_env_compensation`, `inject_to_buffer`, `output_pretty`, `output_csv`, per-gas `<name>_en/_offset/_inject` × 8) plus live readings (`last_co2/co/nh3/nox/alcohol/benzene/smoke`, `last_aqi`, `last_rs`, `last_ratio`, `last_raw_adc`, `warmed_up`, `warmup_remaining_sec`, `last_reading_time`).

### `POST /api/mq135-config` (`:406`)

`updateFromJson(req.body)` (`sensor_mq135_config.cpp:279`): applies only present keys; `read_interval_sec` clamped `max(60, …)` (same 1m minimum as env sensor); re-applies R0/pin to driver (`setR0` + `begin()`); `saveToFile()`. Success → `{"ok":true}`; failure → 400 `{"ok":false,"msg":"Erro ao guardar config MQ-135"}` (PT string, see MQ135-5). On success re-registers history extra slots (`:409-411`).

### `POST /api/mq135-measure` (`:418`)

Pulls AHT20 temp/humidity when compiled in, `performReading(t, h)`, returns full `toJson()`.

### `POST /api/mq135-calibrate-r0` (`:431`)

Reads, takes `getCurrentRs()`; invalid → 400 `{"ok":false,"msg":"Sem leitura RS valida. …"}` (PT); else `setR0(rs)` + `updateFromJson('{"r0":…}')` (persists) → `{"ok":true,"r0":…}`.

Ethernet: `ethernetHandleMq135*` wrappers exist (`ethernet_bootstrap_handlers.h:2081-2109`) but only `POST /api/mq135-config` is dispatched (`ethernet_bootstrap_routes.h:677`).

## 8. Persistence

`MQ135ConfigManager::begin("/config/sensor_mq135.json")` (`sensor_mq135_config.h:102`); all saves via `SensorConfigBase::saveToFile()` — atomic `.tmp` → `bytes>0` → remove original → rename (`sensor_config_base.h:101-111`). `updateFromJson` saves on every config POST and every R0 calibration (`sensor_mq135_config.cpp:320,448`). Last-reading cache (`last_*`, `last_reading_time`) is persisted alongside config. History slot enable state is derived at boot/post-save via `registerExtraSlots()` (`sensor_mq135_config.cpp:50-84`), which clears slots 0–5 when the sensor is disabled.

## 9. Runtime engine

- **Driver** `chatgpt/src/sensors/sensor_mq135.{h,cpp}`: `begin(pin, r0)` (12-bit ADC, 11 dB, pin range check `>47`, `sensor_mq135.cpp:24-44`); `update(t, h)` averages `MQ135_SAMPLES` (10) reads, `computeRs()` (`RL·(Vcc/Vadc−1)`), per-gas `computePPM(ratio, PARA, PARB)` with datasheet constants (`sensor_mq135.h:68-87`), AHT20 correction applied to CO2 only (`getCorrectionFactor`, reference 20 °C/65 %RH), `computeAQI()` CO2→0–500 scale (`:108-114`); 3 min warm-up (`MQ135_WARMUP_MS`, `isWarmedUp`/`getWarmupRemaining`).
- **Manager** `sensor_mq135_config.{h,cpp}`: `performReading()` (`:90`) gates on `sensor_enabled`, adds per-gas offsets, stamps `last_reading_time` (unix, 0 if clock unset), `markReadingDone()`, optional `injectToBuffer()` (pretty and/or CSV, `formatPretty`/`formatCSV` at `:154-203`); `stageHistorySlots()` (`:134`) writes fixed slots 0–5 (CO2 scale 1, CO/NH3/NOx/Alcohol ×10, AQI ×1; benzene/smoke display-only).
- **Scheduler** `sensor_config.cpp:789-796`: when AHT20 page enabled, `SensorConfigManager::performReading()` triggers `mq135ConfigManager.performReading(last_temp_avg, last_humidity)` only when `shouldAutoRead()` (own `read_interval_sec`) elapses, then stages history slots.
