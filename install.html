Flash a board

Three ways in, depending on where the board is: a browser over USB, a terminal over USB, or OTA when it is already on the network and running.

What is in the download

  • firmware.bin — the application image, OTA-signed. This is the file you upload for a normal update.
  • bootloader.bin and partitions.bin — only for a first install or a full reflash.
  • flash_command.txt — the exact esptool command for that build, written at build time.
  • LICENSE, SBOM.md, THIRD_PARTY_NOTICES — licence material that travels with the binary.

1, Browser, over USB (recommended for the first flash)

  1. Open the Node32-HUB WebFlasher and start it (start-dual.bat on Windows, or serve the page on port 8765).
  2. Connect the board with a USB cable and click Connect — Chrome or Edge, the chip is detected automatically.
  3. Pick Update to write only firmware.bin (keeps bootloader, partitions and your configuration) or Full Install for a board that has never had this firmware.
  4. Use Select build folder… and point it at the unzipped release folder, so the right files are picked for you.
  5. Flash and watch the serial monitor; it prints the boot log and the address the board took.

2, Terminal, over USB (esptool)

  1. Install esptool: pip install esptool.
  2. Unzip the release and open flash_command.txt — it holds the command for that exact build.
  3. Run it from inside the folder. Update only: esptool.py --chip auto write_flash 0x10000 firmware.bin. Full install: the offsets in the file.
  4. If the port is busy, close the WebFlasher or the serial monitor first.

3, OTA, on a board already running

  1. Open http://<device-ip>/ota (or the mDNS name, e.g. cam-m.local).
  2. Upload firmware.bin and let it reboot.
  3. The image is verified against the built-in RSA key before boot; a modified binary is rejected. If a board refuses an OTA, flash it over USB once.

After flashing

  • The board starts an access point NODE32-HUB (password 12345678) — open 192.168.4.1 and set Wi-Fi. Ethernet boards take a DHCP lease instead.
  • Log in with root / root and change both passwords on the first visit.
  • Pack-specific wiring (DB9 jumpers, sensor inputs, I2S, USB Host) is on each pack page.
