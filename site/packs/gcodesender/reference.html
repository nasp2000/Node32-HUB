Every setting

The panel does the preview work in the browser and only sends bytes; this page explains each control on it.

1. The USB link

ControlWhat it does
USB Host on / offS3 boards only: opens the host port. On the P4 the port is always available and the button is replaced by Reconnect.
BaudSerial speed to the controller. Most GRBL boards answer at 115200.
ReconnectRe-opens the port after the controller was power-cycled.
USB-CDC stateShows whether the controller answered, and the last error.

2. Running a job

ControlWhat it does
Jog pad and stepManual moves; the step decides the distance per tap.
Feed overrideScales the programmed feed while the job runs.
Pause / Resume / CancelPause keeps the position; cancel stops the stream.
Resume from lineAfter an alarm interrupted a job, restarts at the recorded line — only with the safety box ticked.
Command boxSends raw G-code or a macro, one line at a time.
MacrosSaved snippets for the commands you type most.

3. Files and probing

ControlWhat it does
SD / PSRAM listG-code on the card (up to 50 MB) or in PSRAM; load one and stream it.
Probe Z zeroSets Z zero on contact.
Probe gridGenerates the measurement grid for a height map.
Height mapMeasures and stores the surface, then applies it while streaming.
PreviewToolpath, bounds and heatmap, computed in the browser — the board does not draw it.

4. Hardware

ItemDetail
BoardESP32-P4 with USB Host (native OTG).
ControllerAny GRBL board with a CH340/CH341 USB bridge.
StoragemicroSD for the file library; PSRAM for streaming.
LaserDiode heads in GRBL laser mode, with power overrides.
