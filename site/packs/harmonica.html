Harmonica Box

Internet radio that behaves like a radio: turn it on, pick a station, it plays. Streams decode on the board and leave through I2S, with UPnP browsing for whatever runs on your own network.

What it does

  • Decoders — MP3, FLAC, OGG/Opus, AAC and WAV, buffered in PSRAM.
  • I2S output — UDA1334A DAC, clean clock, no PWM trickery.
  • UPnP / DLNA — browse a media server on the local network and queue from it.
  • Alarms — schedule a station for a time of day, with a volume ramp.
  • Station favicons — the logo comes from the stream metadata, no catalogue to maintain.

Install

  1. Flash firmware.bin over USB with the WebFlasher, or update at /ota. Full guide: how to flash.
  2. Join NODE32-HUB (password 12345678) and open 192.168.4.1.
  3. Set Wi-Fi, then add stations by URL or browse UPnP.
  4. Wire the DAC to the I2S pins and set the output volume on the radio page.

Hardware

  • Board — ESP32-S3 N16R8 (PSRAM buffers the stream).
  • Output — I2S to a UDA1334A breakout, line out to an amplifier.
  • Network — Wi-Fi, or Ethernet on boards that have it.
  • Optional — encoder and buttons for volume and station.
