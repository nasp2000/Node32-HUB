Every setting

What each field on the RAMBOX page does, the values it accepts and what happens when you leave it alone. The page has five tabs: Config, Arrivals, Pigeons, Race and State.

Wiring the DB9

The Unikon clock only transmits while it sees that jumper: pin 9 is the signal it watches, and pin 5 is ground. Without it the bus stays silent and the page shows no data — this is the first thing to check when the clock does not answer.

1. Which clock are you talking to

One module at a time. Enabling one disables the other, and the RS232 profile switches with it.

FieldValuesDefaultWhat it does
Device Unikon · Bricon the active module Selects which clock the page controls. On the first status read the selector adopts whichever clock is actually enabled; the remembered choice only wins when none is active.
Clock active on · off off Starts polling the selected clock. The badge next to the selector shows the live state. Turning one on turns the other off.

2. Polling and the serial profile

FieldValuesDefaultWhat it does
Poll interval 1 · 3 · 5 · 10 · 15 · 30 · 60 min 3 min How often the clock is queried. Short intervals catch arrivals sooner and put more traffic on the bus. A stored value outside the list snaps to the next larger step.
Use the RS232 settings on · off off Bench mode: the module stops applying its own serial profile and uses whatever is configured on the /rs232 page. The module's profile is never overwritten and comes back when the box is cleared.
Restore module profile button — Re-applies the module's stored serial profile. It is an action, not a save: unsaved edits on screen stay unsaved and nothing else in the configuration changes.

3. Unikon

FieldValuesDefaultWhat it does
Official format on · off off Uses the official band format for the arrivals, as the federation reads them, instead of the clock's raw fields.
Loft email address empty Destination of the loft list mail. Without an address the button does nothing.
Line fixed 9600 8N1 The Unikon bus is fixed; there is nothing to tune. If the clock does not answer, check the DB9 jumper on the pack page first.

5. Buttons

ButtonWhereWhat it does

6. The five tabs

TabShows
ConfigDevice selector and every field in sections 1 to 4.
ArrivalsClock state, arrival count, the arrival table (ring, time, race) and the sync/poll actions.
PigeonsThe loft list read from the clock, plus the loft email.
RaceRaces stored in the clock, read-only.
StateEvery status field the module reports: clock, fancier, race, arrivals, RS232 state and the last poll.

The selected tab and the selected device are remembered in the browser, not on the board.

7. Email

Arrival mails and the loft mail use the shared SMTP account. Without a working account, arrivals are only visible on this page.

The account, the recipients and the test send are the same on every pack — see Email in the shared reference.
