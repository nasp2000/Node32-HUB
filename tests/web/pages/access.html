🏠 Home

🔒 Access

👥 Web Sessions

Controls how many browsers can be connected at the same time and for how long.

📄 Local Processing Pages

Pages that run processing locally in your browser.
When active, sessions on local processing pages are not removed by timeout. They still count toward the session limit.

📟 Monitoring

Controls visibility of monitoring features on the main page.
When active, the 📟 Serial Monitor button appears in the Monitoring section of the home page.

👤️ Users

Manage administrator and viewer accounts.

🔐 Administrator

Full access to all pages and configurations.
When active, browsers must log in with the administrator credentials below. Disabled by default — access is open.
Passwords do not match.

👁️ Viewer

Read-only access to a limited set of pages. Cannot change settings.
🔒 The viewer can access: /, /status, /sensor-charts, /monitor, /files — view only, cannot change settings or execute actions.
