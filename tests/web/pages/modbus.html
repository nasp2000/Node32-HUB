ⓘ Legenda dos campos de registo (clique para expandir)

Cada registo configura um valor a ler (ou escrever) no dispositivo escravo Modbus.

Campo Descrição
AddrEndereço do registo no dispositivo escravo (0–65535), conforme manual do equipamento.
FCFunção Modbus: FC3=Holding Registers (R/W), FC4=Input Registers (só leitura), FC1=Coils (bits R/W), FC2=Discrete Inputs (bits só leitura).
TipoFormato do valor: INT16/UINT16=1 registo (16 bits), INT32/UINT32/FLOAT32=2 registos consecutivos (32 bits), BIT=um bit dentro de um registo.
OrderOrdem dos bytes para tipos 32-bit. ABCD=Big-Endian (mais comum), CDAB=Word-swap, BADC=Byte-swap, DCBA=Little-Endian. Ignorado em tipos 16-bit.
BitSó usado com Tipo=BIT. Indica qual dos 16 bits do registo interessa (0=bit menos significativo, 15=mais significativo).
LabelNome livre para identificar o registo na página Live e nos logs do SD card (ex: “Temperatura”).
UnitUnidade de engenharia apresentada no Live ao lado do valor (ex: °C, %, hPa, V, A). Apenas cosmético.
ScaleMultiplicador aplicado ao valor bruto. Ex: 0.1 transforma 253 → 25.3. Use 1 se o valor já está na unidade certa.
OffsetValor somado ao resultado após o scale. Útil para correções de zero. Normalmente 0.
LogSe ativo, o valor é guardado no ficheiro CSV do cartão SD a cada poll.
PrettySe ativo, o valor é apresentado no Live com casas decimais (ex: 25.3 °C). Desativado mostra o inteiro bruto.
