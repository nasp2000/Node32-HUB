⌨️ Commands:

💡 These commands are for use on the command sending pages, sending the command to the system.
📧 EMAILDAY — Sends current day files by email
Example: emailday
📅 EMAILDAY [date] — Sends files from specific date
Example: emailday 29-12-2025
📋 LOGDAY — Sends current day log by email
Example: logday
📋 LOGDAY [date] — Sends log from specific date
Example: logday 28-02-2026
🌡️ SENSORDAY — Sends today's sensor history by email
Example: sensorday
🌡️ SENSORDAY [date] — Sends sensor history from specific date
Example: sensorday 01-03-2026

⚙️ Save received data (microSD/PSRAM):

⏳ Buffer write: Waits for an idle period and writes in bulk (saves SD card writes). Writes earlier if the buffer reaches the limit.
✔️ Active: Yes = Saves data to storage (SD or PSRAM, as available). No = Discards data after use (emails/alerts/recipients).
📄 Format: File type (.txt with timestamps, .csv comma-separated, .bin pure binary).
📧 Email: If active, sends data line by email according to recipients/alerts (in addition to saving if Active=Yes).
⚠️ PSRAM Mode: Data stored in PSRAM is volatile (lost on reboot/power-off). Use only as temporary fallback when SD is not available.
࡛️ Folder name: The folder name where data is saved is based on the System Name configured in the System Settings page (format: "SystemName_DD-MM-YYYY").
